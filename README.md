# Monster Catch

A simple, fast arcade game for kids and teens, made with Godot 4.7.2.
Playable on Android.

## Features
- Combo system, gold star and shield power-ups
- Sound effects and particle effects
- Start screen, pause button and hearts
- Saved high score
- Pixel-art skeleton monster on a dark teal background

## Play
- Android: download the APK from [itch.io](https://dev-piyushrawat.itch.io/monstercatch) or the Releases page on this repo
## Run from source
1. Install Godot 4.7.2
2. Clone this repo
3. Open `project.godot` in Godot and press Play
